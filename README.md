# Фрактальное дерево

**Автор:** Харламова Елизавета Романовна

**Группа:** ПИ25-1

## Описание проекта

Программа рисует фрактальное дерево: от ствола рекурсивно растут ветки,
каждая следующая короче предыдущей и повёрнута на заданный угол.

Лабораторная работа №1 «Простая анимация», задание «Простой фрактал».
